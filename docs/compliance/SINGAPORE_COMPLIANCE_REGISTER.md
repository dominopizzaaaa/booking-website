# Singapore compliance register

Snapshot date: 2026-09-29

Launch market assumed for this review: Singapore

Product snapshot: Courtly booking platform for clubs, coaches, students, and
guardian-managed children

This is a working register, not legal advice or a certification. “Current
state” describes repository evidence observed on the snapshot date, not a
production audit. The accountable roles below must be mapped to named people
and alternates before launch.

## Technical snapshot details

The following observations should be re-run before release because dependencies
and flows can change:

- Necessary first-party cookies: `courtly_session` /
  `__Host-courtly_session` and `courtly_admin` /
  `__Host-courtly_admin`. Both are authentication cookies; JavaScript cannot
  read them. Production adds `Secure`. Neither cookie is evidence of a consent
  decision.
- First-party browser storage: product-tour version and one pending-tour user
  identifier in `localStorage`/`sessionStorage`. No advertising profile was
  found.
- External services visible in code/config: Stripe, Resend, Google Maps/Places,
  Google Calendar, Railway, Vercel, GitHub, and PostgreSQL. Presence in this
  list does not establish the production vendor, legal entity, region, or data
  transfer.
- Public prices are club-entered integer cents formatted in SGD. Club-supplied
  merchant and GST declarations gate and inform checkout, but are unverified;
  the repository contains no legal/GST determination, tax-rate calculation, or
  tax-amount breakdown.
- Production marks the legal set approved only when
  `LEGAL_DOCUMENTS_APPROVED_VERSION` and `LEGAL_DOCUMENTS_APPROVED_HASH` equal
  the exact current constants; that approval is required for registration,
  checkout, and Family consent writes, but code does not prove that accountable
  approval was actually obtained.
- Family routes default off in production. Production permits individual and
  bulk deletion of demo businesses, but hard-disables individual deletion of a
  non-demo business.
- Every privacy-operator mutation snapshots the authenticated operator's stable
  ID, name, and email and requires an external audit reference to the controlled
  case or work record.
- No NRIC/FIN/passport collection or Singpass integration was found.
- No platform-originated SMS, telephone, push, or WhatsApp campaign exists.
  The booking confirmation page's WhatsApp action lets the user initiate a
  share through WhatsApp.
